Setup checklist

  1. Create a Bunny Stream account and video library.
  2. Put the library ID and API key in your server's environment secrets.
  3. Deploy this Node.js project to a server that supports uploads.
  4. Configure access restrictions, domain restrictions and moderation before public launch.

This starter uses a temporary in-memory catalog. It is not production-ready: add a database, authentication/roles, resumable uploads, rate limits, malware/content review, and signed playback before launching.
